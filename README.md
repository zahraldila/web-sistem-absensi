\# Sistem Absensi



Aplikasi sistem absensi berbasis web dengan dukungan \*\*multi-organization\*\* untuk mengelola data pegawai, kehadiran, lokasi, pengajuan, approval, dan monitoring absensi.



\## Features



\- Multi-Organization

\- Manajemen Pegawai

\- Absensi WFO, WFH, dan WFC

\- NFC, GPS, Wi-Fi, dan Selfie

\- Manajemen Role \& Privilege

\- Pengajuan \& Approval

\- Laporan Kehadiran

\- Audit Log

\- TV Monitoring



\## Tech Stack



\- Laravel

\- PHP 8.3+

\- PostgreSQL / Supabase

\- Blade

\- JavaScript

\- Vite
